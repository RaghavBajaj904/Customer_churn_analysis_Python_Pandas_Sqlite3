# Customer Churn Analysis

## 📌 Overview

This project analyzes customer churn using **Python, Pandas, Matplotlib, Seaborn, and SQLite**. Customer, subscription, and support data were cleaned, merged, and analyzed to identify churn patterns and business insights.

## 🎯 Objectives

- Analyze churn and retention
- Compare churn across subscription plans
- Analyze churn by state and month
- Examine churn score and support escalations
- Identify revenue associated with churned customers

## 🛠️ Tools

- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- SQLite
- Jupyter Notebook

## 📊 Key Metrics

| Metric | Result |
|---|---:|
| Churn Rate | 28.57% |
| Retention Rate | 71.43% |
| Avg Revenue/User | 18.85 |
| Avg Tenure | 1,532 days |
| Revenue at Risk | 73.94 (Rs 'K') |
| Escalation Rate | 19.05% |

## 🔍 Key Insights

- Overall churn rate was **28.57%**.
- Churn varied across subscription plans and states.
- **September 2024** recorded the highest monthly churn count.
- Churn showed a strong association with **churn score and escalations**.
- Churned customers accounted for **73.94 (Rs 'K')** in monthly charges.
